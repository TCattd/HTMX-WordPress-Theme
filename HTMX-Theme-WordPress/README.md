# HTMX Theme for WordPress

A dedicated demonstration theme for the HyperPress stack, focusing on **HTMX** and **Alpine Ajax** for hypermedia interactivity.

## Requirements

This theme requires the **HyperPress** plugin to be installed and activated.

## Installation

1. Copy this folder into your WordPress `wp-content/themes/` directory.
2. Activate the theme in the WordPress admin under **Appearance > Themes**.
3. Ensure **HTMX** is selected as the active library in **Settings > HyperPress**.

## Features

- **HTMX Integration:** Real-time updates via `hx-` attributes.
- **Alpine Ajax Integration:** Seamless integration with Alpine.js.
- **Pico CSS:** Lightweight, responsive CSS framework.

## Documentation

Learn how to use HTMX from the [HTMX documentation](https://htmx.org).
Learn how to use Alpine Ajax from the [Alpine Ajax documentation](https://alpine-ajax.js.org/).
For HyperPress specific integration, see the [HyperPress documentation](https://github.com/EstebanForge/HyperPress).
