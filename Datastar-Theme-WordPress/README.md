# Datastar Theme for WordPress

This is a dedicated demonstration theme for the HyperPress stack, using **Datastar v1.0** exclusively for real-time hypermedia interactivity.

## Requirements

This theme requires the **HyperPress** plugin to be installed and activated.

## Installation

1. Copy this folder into your WordPress `wp-content/themes/` directory.
2. Activate the theme in the WordPress admin under **Appearance > Themes**.
3. Ensure **Datastar** is selected as the active library in **Settings > HyperPress**.

## Features

- **Datastar v1.0.1 Integration:** Uses the latest stable syntax.
- **Pico CSS:** Lightweight, responsive CSS framework.
- **Real-time Demos:** Built-in templates showcasing Datastar signals and actions.

## Documentation

Learn how to use Datastar from the [Datastar documentation](https://data-star.dev/).
For HyperPress specific integration, see the [HyperPress documentation](https://github.com/EstebanForge/HyperPress).
